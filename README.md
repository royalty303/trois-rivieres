# Au fil de la ville · Trois-Rivières

Exploration visuelle de l'histoire urbaine de Trois-Rivières, à partir des notes de Maxime Savary
sur la conférence de Gérard Beaudet (Université de Montréal, 19 novembre 2026).

Site statique servi par GitHub Pages : `index.html` + `img/`. Leaflet 1.9.4 est intégré à la page.
Fonds de carte Esri sans clé (ne pas utiliser CARTO, qui exige une clé).
Le plan Goad 1888-1903 et le périmètre du feu de 1908 sont calés par coins (constante `GEO`), écart résiduel ≈ 20 m.
